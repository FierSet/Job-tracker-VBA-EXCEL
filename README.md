🔐 Why are the VBA macros separate?

The Excel file and VBA source code are provided separately.

This makes the VBA code easier to read, review, and understand, while also helping avoid Excel security restrictions that can occur when opening macro-enabled files downloaded from the internet.

The .bas file contains the VBA source code and can be imported into the Excel workbook using the VBA Editor.

📥 How to Use
Download the Excel file from this repository.
Open the workbook with Microsoft Excel.
If necessary, enable editing.
Open the VBA Editor with Alt + F11.
Import the .bas file if you want to use the provided macros.
Review or modify the VBA code as needed.

Note: The exact steps may vary depending on your Excel version and security settings.
